Glossary

  • Connector. A plug-in users add to their own AI, such as Claude, so it can search CHIRPdb.
  • Shared vocabulary. Each country labels things its own way (“fishing vessel”, “fishing”, “trawler”). We map them all onto one list, so counts compare across countries.
  • SHIELD codes. A standard set of codes for the human factors behind an incident. The AI suggests them for each report; CHIRP accepts or corrects them.
  • Review tool. CHIRP’s existing staff screen for checking reports.
  • Ingestion. Adding a source’s reports to CHIRPdb so they can be searched. Automatic ingestion checks each source on a schedule and adds new reports without anyone doing it by hand.
  • Fast ingestion. 2.5 days per country instead of 5. Only some of each country’s reporting rules are built in, so the data is less reliable.
  • Validated test set. A fixed list of questions with known right answers, re-run after every change to catch answers getting worse.
  • Log. A record of each question asked and which reports the AI used to answer it.

Appendix: Scope Doc

Direct quotes from the Insight Engine Tranche 2 Scope Doc, next to the menu item each one supports. Priorities are the Scope Doc’s.

Chat

Menu item Priority Scope Doc
Answers drawn from verified reports, tuned for task briefings Must As a seafarer or supervisor about to start a task, I want to know what has gone wrong during similar work, so that I recognise the critical hazards before I start. … A member of the public asks a task question and receives a briefing in which every claim is cited to a verified report.
Tuned for descriptions of a near miss Must As a seafarer who has just had a near miss, I want to describe what happened, so that I can see whether others have experienced the same thing and what they learned. … A typed description returns related verified incidents, their shared factors and a link to CHIRP’s reporting form.
Every claim cited and checked Must Every claim is cited to source. … Every public answer cites verified records and links to the source report.
Plain maritime English Fixed constraint Outputs are in English only, written in plain maritime English so that users can rely on browser translation.
Toolbox talk format Should As an onboard supervisor, I want the briefing produced as a toolbox talk, so that I can brief the crew from real incidents.
Upload your own document and discuss it Could As an onboard supervisor, I want to upload a draft risk assessment, permit or plan, so that it is challenged against previous incidents before authorisation. … As an organisation or onboard investigator, I want to upload our own report or event narrative, so that I can find comparable cases and lines of enquiry, knowing the document itself is not kept.

Analyst tools and dashboards

Menu item Priority Scope Doc
Proposed coding and similar cases for incoming CHIRP reports Must As a CHIRP analyst, I want each report we receive coded and set against similar cases, so that I can assess it quickly and consistently and respond with context. … A submitted report returns proposed coding and similar cases, and nothing enters the database until verified in the review tool.
Pattern finding for CHIRP analysts Must As a CHIRP analyst, I want to ask questions across all reports and datasets, so that I can unearth patterns and publish insight that raises awareness and encourages improvement. … An analyst query returns pathways with supporting cases, and drafting support produces a reviewable outline.
Dashboards Should As a shore-side manager or commercial operator, I want to explore trends across the evidence base, so that I can find vulnerabilities and decide where to invest. … Dashboards filter by vessel type, date, outcome and country, and every figure traces to verified records.
